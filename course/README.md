# Deep Learning & NLP: A Unified Course

A comprehensive deep learning course synthesizing Stanford's **CS231n** (Convolutional Neural Networks for Visual Recognition) and **CS224N** (Natural Language Processing with Deep Learning).

## Course Overview

This course takes you from neural network fundamentals through large language models, covering all concepts needed to understand and build modern AI systems.

## Prerequisites

- **Programming**: Python proficiency, NumPy basics
- **Math**: Linear algebra, calculus, basic probability
- **ML Basics**: Understanding of supervised learning concepts

## Course Structure

```
Module 1: Neural Network Foundations
├── Neurons and activation functions

└── Network architectures

├── Backpropagation and gradients

├── Regularization (L1, L2, Dropout)
└── Batch normalization

Module 3: Convolutional Neural Networks
├── Convolution operation
├── Pooling layers
├── CNN architectures (LeNet → ResNet)
├── Transfer learning
└── Visualization and interpretation

Module 4: Sequence Models
├── Language modeling basics
├── Recurrent Neural Networks
├── Vanishing/exploding gradients
├── LSTM and GRU
└── Seq2Seq architectures

Module 5: Attention & Transformers
├── Attention mechanism
├── Self-attention
├── Multi-head attention
├── Positional encoding
├── Transformer architecture
└── Vision Transformers

Module 6: Large Language Models
├── Tokenization (BPE, vocabulary)
├── Pre-training objectives
├── Scaling laws
├── Fine-tuning (Full, LoRA, QLoRA)
├── RLHF and alignment
├── Prompting techniques
└── In-context learning

Module 7: Generative Models
├── Autoencoders
├── Variational Autoencoders (VAE)
├── Generative Adversarial Networks (GAN)
├── Diffusion models

Module 8: Advanced Topics & Applications
├── Retrieval-Augmented Generation (RAG)
```

## Key Concepts Covered

This course covers all terms from the Deep Learning & LLM Glossary:

**Core Neural Network Concepts**: ANN, neuron, weight, bias, parameter, layer, deep learning, forward pass, inference, latent space, tensor, hidden state

**Training & Optimization**: Loss function, gradient, gradient descent, SGD, backpropagation, learning rate, optimizer, epoch, batch, convergence, overfitting, underfitting, generalization, hyperparameter, vanishing/exploding gradients

**Network Architectures**: Feedforward, CNN, RNN, LSTM, GRU, Seq2Seq, Encoder-Decoder, Autoencoder, ResNet, U-Net

**Activation Functions**: ReLU, Sigmoid, Tanh, Softmax, Leaky ReLU, GELU, Swish

**Regularization & Normalization**: L1/L2, Dropout, Batch Normalization, Layer Normalization, Early Stopping, Data Augmentation

**Attention & Transformers**: Attention mechanism, Self-attention, Q/K/V, Multi-head attention, Transformer, Positional encoding, Causal masking, Cross-attention, KV cache

**Large Language Models**: LLM, Token, Tokenization, BPE, Vocabulary, Embedding, Pre-training, Next-token prediction, Masked LM, Perplexity, Fine-tuning, Prompt, Few-shot/Zero-shot, Chain-of-thought, Hallucination, Temperature, Sampling methods

**Training Paradigms**: Supervised, Unsupervised, Self-supervised, Semi-supervised, RL, RLHF, PPO, DPO, Transfer learning, Contrastive learning, Knowledge distillation

**Generative Models**: VAE, GAN, Diffusion, Autoregressive models, Latent diffusion

**Deployment & Optimization**: Quantization, Pruning, LoRA, QLoRA, PEFT, KV cache, Speculative decoding, Model serving
